Returns status, progress, criteria, and timestamps for one prospect list. Requires `websets:read`.

## At a glance

|  |  |
| --- | --- |
| Method | `GET` |
| Path | `/api/v2/prospect-lists/{webset_id}` |
| Permission | `websets:read` |
| Returns | `200` with `item` |

The existing `GET /api/v2/websets/{webset_id}` endpoint remains supported with the same parameters, response fields, and permissions. Both URLs execute the same operation.

Imported tables are also readable, with `source`, `total_items`, and `importing` while processing. Search scoring statistics are null. Poll detail and paginate rows for imports; search plans, Find More, and search SSE remain exclusive to Revor searches.

## Request

```bash cURL
curl "https://revor.ai/api/v2/prospect-lists/WEBSET_ID" \
  -H "Authorization: Bearer sk-revor-REPLACE_ME"
```

## Progress fields

<Note>
  After Find More, `verified` can decrease while `qualified` grows. Treat the Items endpoint as the source of truth for visible results.
</Note>

- `goal`: total qualified results intended for delivery.
- `verify_cap`: maximum candidates this run may verify; it is not a result count.
- `verified`: candidates verified in the current create or Find More run; a new run resets this count.
- `qualified`: current `full + partial` pool, which may include unreleased overflow.
- `full`: fully matching results.
- `stop_reason`: why the current run stopped.

## Failure

For `status=failed`, read `failure.code`. An absent Webset or one owned by another user returns `404 webset_not_found`.
