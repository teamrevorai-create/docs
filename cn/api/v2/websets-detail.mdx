查询名单状态、进度、条件和时间信息。需要 `websets:read` 权限。

## 接口概览

|  |  |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/v2/prospect-lists/{webset_id}` |
| 权限 | `websets:read` |
| 返回 | `200`，含 `item` |

原入口 `GET /api/v2/websets/{webset_id}` 继续支持，参数、返回字段和权限均保持一致。两个 URL 执行同一操作。

此接口也支持导入表格，返回 `source`、`total_items` 和导入状态。导入期间为 `importing`，搜索匹配统计为 `null`。导入表格使用详情轮询及行数据分页；搜索策略、Find More 和搜索 SSE 仅适用于 Revor 挖掘名单。

## 请求

```bash cURL
curl "https://revor.ai/api/v2/prospect-lists/WEBSET_ID" \
  -H "Authorization: Bearer sk-revor-REPLACE_ME"
```

## 进度字段

<Note>
  Find More 后 `verified` 变小而 `qualified` 增长是正常现象。最终可见结果以 Items 分页为准。
</Note>

- `goal`：希望交付的合格结果总数。
- `verify_cap`：本轮允许核验的候选上限，不是结果数。
- `verified`：当前一次创建或 Find More 运行已核验的数量；新运行会重新计数。
- `qualified`：当前结果池中的 `full + partial` 数量，可能包含尚未释放的 overflow。
- `full`：完全符合条件的数量。
- `stop_reason`：本轮停止原因。

## 失败

`status=failed` 时读取 `failure.code`。不存在或不属于当前用户的 ID 返回 `404 webset_not_found`。
