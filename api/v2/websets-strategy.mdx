Returns the currently persisted criteria and search strategy. It does not start a model call or search and does not consume credits.

## At a glance

|  |  |
| --- | --- |
| Method | `GET` |
| Path | `/api/v2/prospect-lists/{webset_id}/search-plan` |
| Permission | `websets:read` |
| Returns | `200` with `criteria` and `strategy` |

The existing `GET /api/v2/websets/{webset_id}/strategy` endpoint remains supported with the same parameters, response fields, and permissions. Both URLs execute the same operation. The Webset does not need to be complete.

## Request

```bash cURL
curl "https://revor.ai/api/v2/prospect-lists/WEBSET_ID/search-plan" \
  -H "Authorization: Bearer sk-revor-REPLACE_ME"
```

## Readiness

<Note>
  Display `criteria` after `criteria_ready=true` and `strategy` after `strategy_ready=true`. Before that, `strategy=null`. The SSE `webset.strategy` event sends the same complete presentation snapshot.
</Note>
