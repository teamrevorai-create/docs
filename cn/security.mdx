Revor AI 通过访问控制、加密、备份和监控等措施保护数据并保障平台稳定运行。以下说明各项控制的具体范围。

## 账户访问与权限

- **登录与团队：** 支持邮箱密码登录、重置密码，并可通过邀请和移除管理团队成员。
- **基于角色的访问：** 角色控制对管理类和业务类 API 的访问。Open API 支持细粒度权限。
- **已连接的 AI 客户端：** MCP 客户端使用授权它的 Revor 账户权限。你可以撤销 OAuth 授权或轮换 API Key 来终止访问。

## 加密与数据保护

- **传输中的数据：** 网络通信使用 TLS 1.2 或 TLS 1.3。
- **存储的敏感凭证：** 存储的敏感凭证和 OAuth 令牌使用 AES-256-GCM 加密，加密密钥与应用代码分开管理。
- **数据访问与恢复：** 按用户范围的访问控制限制数据访问。数据库每日自动备份，并进行完整性校验。

## 平台防护

- **API 防护：** 部分高风险 API 接口设有频率限制。
- **活动记录：** 结构化访问日志和任务事件追踪支持监控。应用日志会轮转并压缩。
- **注册风控：** 使用邮箱、域名和 IP 地址信号进行注册风险控制。

## 隐私与法律信息

阅读 [隐私政策](https://revor.ai/privacy-policy)，了解 Revor 如何处理个人数据，包括收集、使用、共享、安全、保留以及可行使的隐私权利。其补充说明解释了通过已连接的 Google Workspace 和 Gmail 账户访问的数据、这些数据的用途，以及如何断开连接或申请删除。该政策区分了受政策约束的个人数据与受相关客户协议约束的客户数据。

[使用条款](https://revor.ai/terms-of-service) 说明了账户责任和可接受的使用方式。REVOR 商标已在中国内地、新加坡、中国香港特别行政区和欧盟注册。如有与你所在组织相关的安全或合规问题，请[联系 Revor 支持团队](mailto:support@revor.ai)。
