两个接口都创建异步任务，结果通过任务对象返回。`Idempotency-Key` 是可选的；需要安全重试时建议发送并复用同一个值。

你可以发送 `Prefer: wait=20`。如果任务在等待窗口内结束，接口直接返回 HTTP `200`；否则返回 HTTP `202`，调用方继续轮询 `/api/v2/jobs/{id}`。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/v2/research/public-web` | 根据查询词搜索公开网页资料。 |
| `POST` | `/api/v2/research/contacts` | 根据企业官网域名搜索联系人。 |
