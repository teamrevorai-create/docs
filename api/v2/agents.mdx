These endpoints reuse Console configuration services. Website creation uses a separate backend workflow; the corresponding [MCP management tools](/mcp/tools) reuse these public services.

<Note>
  Use `Authorization: Bearer <API_KEY>`. Resources are scoped to the key owner. The rolling user-default preset includes these permissions; the readonly preset only includes `agents:read`. Explicit denials remain effective. Minimum tier: Free.
</Note>

Reads use the `read` rate-limit bucket. Writes use `outreach_write`.

## Shared concepts

### Response envelope

Successful responses use the standard envelope:

```json
{
  "ok": true,
  "request_id": "string",
  "item": { ... }
}
```

List responses include `items`, `total`, `page`, and `limit`.

### Agent summary vs detail

Summaries expose `id`, `name`, `description`, `status`, `default_mode`, `generation_contract_version`, and `updated_at`. Detail responses additionally include editable configuration, `config_mode`, `created_at`, and `channel_bindings`.

Each `linkedin`/`whatsapp`/`email` binding is `null` or an object containing `account_id` and `bound_at`. Use the existing `GET /api/v2/connect/accounts` to select an account.

### Optimistic concurrency

Every mutation requires `expected_updated_at`, copied exactly from the latest detail response. Stale versions return `409`; read and reconcile changes before retrying.

## Errors and retries

| HTTP | Code | Meaning |
| --- | --- | --- |
| `400` | `agent_input_invalid` | Request does not match the contract |
| `400` | `agent_configuration_invalid` | Violates business validation rules |
| `403` | `permission_denied` | Missing required permission |
| `404` | `agent_not_found` | Agent does not exist, was deleted, or belongs to another user |
| `404` | `agent_sequence_unavailable` | Feature not enabled for this agent |
| `409` | `agent_config_conflict` | Version expired or concurrent modification |
| `409` | `agent_sequence_config_conflict` | Sequence version expired or concurrent modification |
| `409` | `agent_account_already_bound` | Account occupancy conflict |
| `409` | `agent_knowledge_base_not_found` | Linked knowledge base is unavailable |
| `500` | `agent_operation_failed` | Operation failed. Read current state before retrying |

### Retry rules

- Base configuration reads, edits, and binding operations are synchronous.
- Website creation, content generation, and message previews return asynchronous jobs.
- Sequence publication returns its version synchronously; workers synchronize linked plans.

<Warning>
  Base configuration persistence and subsequent side effects are not one transaction. After a `500`, read current state before retrying. Replaying an old base configuration version returns a conflict rather than an idempotent success.
</Warning>
