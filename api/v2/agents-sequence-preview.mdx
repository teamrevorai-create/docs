Preview a follow-up message for a saved and enabled outreach sequence.

## Overview

|  |  |
| --- | --- |
| Method | `POST` |
| Path | `/api/v2/agents/{agentId}/sequence/preview` |
| Permission | `agents:write` |
| Idempotency | Required (`Idempotency-Key` header) |
| Rate limit | `expensive_create` |
| Returns | Public job (poll `GET /api/v2/jobs/{id}`) |

## Path parameter

<ParamField path="agentId" type="string" required>
  UUID of the agent with an icebreaker configuration.
</ParamField>

## Request body

<ParamField body="config_version" type="integer" required>
  Must match the saved sequence version.
</ParamField>

<ParamField body="round_no" type="integer" required>

```bash cURL
curl -X POST "https://revor.ai/api/v2/agents/{agentId}/sequence/preview" \
  -H "Authorization: Bearer sk-revor-REPLACE_ME" \
  -H "Idempotency-Key: seq-preview-001" \
  -H "Content-Type: application/json" \
  -d '{
    "config_version": 1,
    "round_no": 2,
    "channel": "email",
    "locale": "en",
    "research": false,
    "first_touch_subject": "Introduction",
    "first_touch_text": "The first preview message",
    "recipient_name": "Alice",
    "recipient_company": "Example Manufacturing",
    "prior_preview_messages": []
  }'
```

### Research previews

`research=true` requires the round's `preview_research_enabled` and either `first_touch_run_id` or a client-generated `preview_thread_id` UUID. `previous_run_id` may reference the most recent earlier research preview. These run IDs are `research_run_id` from preview results, not public job IDs. Reuse the same thread ID across a preview thread. Owner, agent, recipient, and referenced first/prior message text must match. Ordinary previews reject research run references. Approved Meta templates are previewed directly and cannot add research.

### Billing

- Ordinary previews consume one ordinary outreach unit.
- Research previews consume one research unit without an extra ordinary charge.
- Results include `messages`, `agent_id`, `agent_version`, `config_version`, `round_no`, `research_run_id`, and billing.
- Retries reuse frozen configuration.
- Confirmed failures refund reservations.
- Unknown outcomes retain the original batch for recovery without regenerating.
- Cancellation is allowed only before first execution.

<Note>
  Save and enable the sequence first. Poll `GET /api/v2/jobs/{id}` with `agents:read`.
</Note>
