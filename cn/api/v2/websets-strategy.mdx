返回当前已持久化的条件与搜索策略，不触发新的模型调用、搜索或积分消耗。

## 接口概览

|  |  |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/v2/prospect-lists/{webset_id}/search-plan` |
| 权限 | `websets:read` |
| 返回 | `200`，含 `criteria` 与 `strategy` |

原入口 `GET /api/v2/websets/{webset_id}/strategy` 继续支持，参数、返回字段和权限均保持一致。两个 URL 执行同一操作。名单无需等待完成。

## 请求

```bash cURL
curl "https://revor.ai/api/v2/prospect-lists/WEBSET_ID/search-plan" \
  -H "Authorization: Bearer sk-revor-REPLACE_ME"
```

## Readiness

<Note>
  `criteria_ready=true` 后可以展示 `criteria`；`strategy_ready=true` 后可以展示 `strategy`。未准备好时 `strategy=null`。同样的完整快照也会通过 SSE 的 `webset.strategy` 事件发送。
</Note>
