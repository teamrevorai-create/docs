## 接口概览

|  |  |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/v2/agents/{agentId}` |
| 权限 | `agents:read` |
| 限流桶 | `read` |
| 返回 | 单个 `item`，含完整配置与绑定信息 |

## 路径参数

<ParamField path="agentId" type="string" required>
  智能体 UUID。
</ParamField>

```bash cURL
curl -X GET "https://revor.ai/api/v2/agents/{agentId}" \
  -H "Authorization: Bearer sk-revor-REPLACE_ME"
```

## 响应

```json 200
{
  "ok": true,
  "request_id": "req_xxx",
  "item": {
    "id": "agent-uuid",
    "name": "客户开发助手",
    "description": "面向制造业的主动触达智能体",
    "status": "active",
    "default_mode": "icebreaker",
    "config_mode": "advanced",
    "generation_contract_version": 2,
    "updated_at": "2026-11-13T04:44:50.096+00:00",
    "created_at": "2026-11-01T08:00:00.000+00:00",
    "channel_bindings": {
      "email": {
        "account_id": "account-uuid",
        "bound_at": "2026-11-10T12:00:00.000+00:00"
      },
      "linkedin": null,
      "whatsapp": null
    }
  }

```

### 渠道绑定

`channel_bindings` 包含 `linkedin`、`whatsapp`、`email`；未绑定为 `null`，已绑定为:

```json
{
  "account_id": "UUID",
  "bound_at": "timestamp"
}
```

查询可用账号继续使用 `GET /api/v2/connect/accounts`。

## 行为说明

- 所有修改必须提供最近一次 GET 返回的 `updated_at`，原样作为 `expected_updated_at`。
- 智能体不存在、已删除或不属于当前用户返回 `404` `agent_not_found`。
