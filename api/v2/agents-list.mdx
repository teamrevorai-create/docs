List agents with pagination and optional filtering.

## Overview

|  |  |
| --- | --- |
| Method | `GET` |
| Path | `/api/v2/agents` |
| Permission | `agents:read` |
| Returns | `items`, `total`, `page`, and `limit` |

## Query parameters

<ParamField query="page" type="integer" default="1">
  Page number.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Maximum `100`.
</ParamField>

<ParamField query="status" type="string">
  Filter by status: `draft`, `active`, `paused`, or `archived`.
</ParamField>

<ParamField query="default_mode" type="string">
  Filter by mode: `icebreaker` or `autoreply`.
</ParamField>

<ParamField query="keyword" type="string">
  Name search filter.
</ParamField>

Unknown parameters are rejected.

## Request example

```bash cURL
curl -X GET "https://revor.ai/api/v2/agents?page=1&limit=20" \
  -H "Authorization: Bearer sk-revor-REPLACE_ME"
```
