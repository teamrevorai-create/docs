REVOR AI MCP 让支持 MCP 的 AI 客户端使用潜客发现、企业研究、联系人搜索、海关贸易数据和授权触达工具。这是远程 MCP 服务，无需安装或运行本地服务器。

## 服务器地址

```text
https://revor.ai/api/mcp
```

支持远程 MCP OAuth 的客户端可以在浏览器中完成授权。使用 API Key 的客户端应将 Key 保存在私密的 `x-api-key` Header 或 Secret 中。不要把 API Key 发到聊天中，也不要写入共享配置或代码仓库。

## 可以完成什么

- 创建企业或人物潜客名单并查看结果。
- 研究企业与市场，按企业官网域名寻找业务联系人。
- 发现进口商、出口商并分析海关贸易数据。
- 查看积分、已连接的发送账号和异步任务结果。
- 在用户确认后，通过已授权账号执行触达。

客户端可见的工具取决于授权权限。
