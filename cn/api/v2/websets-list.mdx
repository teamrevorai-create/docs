分页查询 API Key 所属用户的 Revor AI 潜客名单。需要 `websets:read` 权限。

<Note>
  原入口 `GET /api/v2/websets` 继续支持，参数、返回字段和权限均保持一致。两个 URL 执行同一操作。
</Note>

## 概览

|  |  |
| --- | --- |
| 方法 | `GET` |
| 路径 | `https://revor.ai/api/v2/prospect-lists` |
| 权限 | `websets:read` |

## 请求示例

```bash cURL
curl --get \
  --url "https://revor.ai/api/v2/prospect-lists" \
  --header "Authorization: Bearer sk-revor-REPLACE_ME" \
  --data-urlencode "limit=20" \
  --data-urlencode "target_kind=company"
```

## Query 参数

<ParamField query="limit" default="20" type="integer">
  每页返回数量，范围为 `1` 至 `100`。
</ParamField>

<ParamField query="target_kind" type="string">
  按 `company`（企业）或 `person`（人物）筛选。不传时不筛选。
</ParamField>

<ParamField query="cursor" type="string">
  上一页返回的 `next_cursor`。请原样传递，不要解析或修改。
</ParamField>

## 分页读取

`has_more=true` 时把 `next_cursor` 原样传给下一次请求。该 cursor 只用于 REST 分页，不是 SSE 的 `stream_cursor`。

<Accordion title="挖掘名单与导入表格">
  列表包含挖掘名单与 CSV/XLSX 导入表格。新增 `source` 字段区分 `revor`、`tabular_import` 和历史 `csv_import`；`total_items` 返回已保存的行数。导入进行中状态为 `importing`，导入表格的搜索目标及匹配验证统计为 `null`。
</Accordion>
