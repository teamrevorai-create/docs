## 接口概览

|  |  |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/v2/research/public-web` |
| 权限 | 请联系管理员确认您的产品套餐是否包含此接口。 |
| 返回 | 带来源列表的异步任务结果 |

## 请求

`Idempotency-Key` 是可选的；需要安全重试时建议发送并复用同一个值。可以发送 `Prefer: wait=20`。如果任务在等待窗口内结束，接口直接返回 HTTP `200`；否则返回 HTTP `202`，调用方继续轮询 `/api/v2/jobs/{id}`。

### 参数

<ParamField body="queries" type="string[]" required>
  1-2 条查询；每条最多 500 字符。
</ParamField>

<ParamField body="search_limit" type="integer">
  每条 query 返回 1-10 个来源，默认 10。
</ParamField>

<ParamField body="category" type="string">
  限定优先返回的页面类型： `company`、`news`、`financial report`、`people`、`personal site`。例如 `news` 用于新闻页面，`people` 用于人物相关页面。
</ParamField>

<ParamField body="include_domains" type="string[]">
  最多 5 个域名。
</ParamField>

<ParamField body="user_location" type="string">
  两位国家代码，例如 `US`。
</ParamField>

### 请求示例

```bash cURL
curl -X POST "https://revor.ai/api/v2/research/public-web" \
  -H "Authorization: Bearer sk-revor-REPLACE_ME" \
  -H "Content-Type: application/json" \
  -H "Prefer: wait=20" \
  -d '{
    "queries": ["Banbros Commercial Inc company profile"],
    "search_limit": 5,
    "category": "company",
    "include_domains": [],
    "user_location": "US"
  }'
```

## 响应示例

```json 200
{
  "status": "complete",
  "queries": ["Banbros Commercial Inc company profile"],
  "searched_queries": 1,
  "results_per_query": 5,
  "results": [

      "sources": [
        {
          "url": "https://example.com/company",
          "title": "Company Profile",
          "published_date": null,
          "author": null,
          "image": null,
          "highlights": ["..."],
          "text": "..."
        }
      ]
    }
  ],
  "errors": []
}
```

### 行为说明

- 单个 query 失败而其他 query 成功时，`status` 可能为 `partial`，失败项记录在 `errors`。
- 每个来源正文会被限制长度；`...[truncated]` 表示该来源的正文已按返回长度裁剪。

## 错误码

| HTTP | 说明 |
| --- | --- |
| `400` | 参数无效或请求格式错误 |
| `403` | 该产品套餐不包含此接口 |
| `202` | 任务仍在执行中，请轮询 `/api/v2/jobs/{id}` |
