Revor AI uses access controls, encryption, backups, and monitoring measures designed to protect data and support platform reliability. The controls below describe their specific scope.

## Account access and permissions

- **Sign-in and teams:** Sign in with email and password, reset a password, and manage team members through invitations and removal.
- **Role-based access:** Roles control access to administrative and business APIs. Open API access supports granular permissions.
- **Connected AI clients:** An MCP client uses the permissions of the Revor account that authorized it. You can revoke an OAuth grant or rotate an API key to end that access.

## Encryption and data protection

- **Data in transit:** Network communications use TLS 1.2 or TLS 1.3.
- **Sensitive credentials at rest:** Stored sensitive credentials and OAuth tokens use AES-256-GCM encryption. Encryption keys are managed separately from application code.
- **Data access and recovery:** User-scoped access controls limit data access. Automated database backups run daily and include integrity checks.

## Platform safeguards

- **API protection:** Selected high-risk API endpoints have rate limits.
- **Activity records:** Structured access logs and task event tracking support monitoring. Application logs are rotated and compressed.
- **Registration controls:** Email, domain, and IP address signals are used for registration risk controls.

## Privacy and legal information

Read the [Privacy Policy](https://revor.ai/privacy-policy) for how Revor handles personal data, including collection, use, sharing, security, retention, and available privacy rights. Its supplemental notice explains the data accessed through connected Google Workspace and Gmail accounts, how that data is used, and how to disconnect or request deletion. The policy distinguishes personal data covered by the policy from customer data governed by the relevant customer agreement.

The [Terms of Use](https://revor.ai/terms-of-service) describe account responsibilities and acceptable use. For security or compliance questions specific to your organization, [contact Revor support](mailto:support@revor.ai).
