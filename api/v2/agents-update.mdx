Partially update an agent's configuration.

## Overview

|  |  |
| --- | --- |
| Method | `PATCH` |
| Path | `/api/v2/agents/{agentId}` |
| Permission | `agents:write` |
| Returns | `item` with its new version |

## Path parameter

<ParamField path="agentId" type="string" required>
  UUID of the agent to update.
</ParamField>

## Request body

<ParamField body="expected_updated_at" type="string" required>
  Copied exactly from the latest detail response. Ensures optimistic concurrency.
</ParamField>

<ParamField body="name" type="string">
  Agent name.
</ParamField>

<ParamField body="description" type="string">
  Nullable. Can be cleared with `null`.
</ParamField>

<ParamField body="status" type="string">
  Agent status.
</ParamField>

<ParamField body="channel_scope" type="array">
  Channel scope array.
</ParamField>

<ParamField body="style_tags" type="array">
  Style tags array.
</ParamField>

<ParamField body="tags" type="array">
  Tags array.
</ParamField>

## Request example

```bash cURL
curl -X PATCH "https://revor.ai/api/v2/agents/{agentId}" \
  -H "Authorization: Bearer sk-revor-REPLACE_ME" \
  -H "Content-Type: application/json" \
  -d '{
    "expected_updated_at": "2026-11-13T04:44:50.096+00:00",
    "name": "Sales assistant",
    "description": null
  }'
```

## Response

```json 200
{
  "ok": true,
  "request_id": "req_xxx",
  "item": {
    "id": "agent-uuid",
    "name": "Sales assistant",
    "updated_at": "2026-11-13T04:44:50.096+00:00"
  }
}
```

### Behavior

- Stale versions return `409`; read and reconcile changes before retrying.
- Omitted fields remain unchanged.
- Nullable text can be cleared with `null`.
- Arrays can be cleared with `[]`.
- Unknown fields, incorrect types, and empty patches are rejected.
- Successful writes return `item` with its new version.

<Note>
  Writes use the `outreach_write` rate-limit bucket.
  Existing V1/V2, required-field, and limit normalization rules apply. Mode/version conversion is unsupported. The independent `icebreaker_ai_content` and `icebreaker_fixed_template` drafts are editable.
</Note>

<Warning>
  Attachment uploads, advanced model settings, and whole `channel_settings` objects are outside this public contract. Internal metadata, scraping snapshots, and credentials are excluded from public output.
</Warning>
